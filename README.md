<h2>📖 Sobre o Projeto</h2>
<p>O Genix Solutions é um site institucional fictício desenvolvido para apresentar uma empresa de tecnologia especializada em soluções digitais, transformação digital, desenvolvimento de sistemas e inovação.</p>
<p>O projeto foi construído utilizando tecnologias front-end simples e acessíveis, com foco em organização, navegação intuitiva e design responsivo.</p><br>
<h2>✨ Funcionalidades</h2>
🏠 Página inicial com identidade visual da empresa
👥 Seção "Sobre Nós"
💡 Seção Produtos
🤝 Área de parceiros estratégicos
❓ Seção FAQ com perguntas frequentes
📱 Links para redes sociais
📍 Informações de contato
🎨 Layout responsivo utilizando W3.CSS<br>
<h2>🛠️ Tecnologias Utilizadas</h2>

CSS3
